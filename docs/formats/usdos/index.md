# US-DOS

Back in the early 1990's a student from Bulgaria created MS-DOS alike Operating System for Pravetz 82/8A/8C/8M (Apple II clones), called US-DOS (Universal Software DOS) 

Some of the features included virtual drives, script files, a built-in timer, 40- and 80-column support, and conversion tools.

It is unknown if there is a 2.0 avaliable or if the source is avaliable.
