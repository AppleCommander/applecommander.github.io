There are a number of command-line tools associated with AppleCommander:

* [`ac`](ac.md): The original AppleCommander command-line tool for disk manipuliation.
* [`acx`](acx.md): The "experimental" new AppleCommander command-line tool for disk manipulation and exploration.
* [`acdasm`](acdasm.md): The AppleCommander disassembler command-line tool.
* [`asu`](asu.md): The AppleSingle tool.
* [`bt`](bt.md): The BASIC tools command-line utiltiy.
* [`st`](st.md): The shape table tools command-line utiltiy.
