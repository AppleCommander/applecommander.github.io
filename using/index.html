Here is a relatively current collection of the AppleCommander application across a variety of environments.

Launch window

The control panel is the starting place for everything available in AppleCommander:

Viewing disks

A disk can be viewed in three modes: * Standard: just name, type, size, and locked. * Native: all the details expected when using that operating system * Detail: every piece of information is visible

When a disk image is opened, it is initially in the standard view:

But, that can be toggled to a more native view:

File viewing

File can be viewed as well. Many file types are decoded and displayed. Note that the font size or image size can be increased with the + and - buttons.

... and increased to 12pt:

Note

Windows is actually 13pt. From experimentation, Mac and Linux show definitive font increases from 10pt to 12pt; but Windows needed 10pt to 13pt to show a size increase.

Disk usage map

For each disk that is opened, a disk usage map is available. Note that "block" devices and "track and sector" devices are displayed differently.
